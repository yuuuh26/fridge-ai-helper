# 冷蔵庫AIヘルパー

冷蔵庫・冷凍庫にある食材を登録し、「必ず使う」「使ってもOK」に分類して、料理AI向けの文章をワンタップでコピーする個人用PWAです。

## 公開URL

https://yuuuh26.github.io/fridge-ai-helper/

クラウド版（v1.1.0）：https://fridge-ai-helper-backups.dengana-10011212.workers.dev/

## 主な仕様

- 食材カードのタップで3状態を切り替え
- 残量・単位・冷凍状態をIndexedDBへ自動保存
- 最大5個の冷蔵庫を切り替え。現在の冷蔵庫から完全コピー、選択状態を解除する項目コピー、空の新規作成に対応
- 既存の食材・調味料は更新時に「自宅」へ引き継ぎ、冷蔵庫ごとに独立保存
- 全冷蔵庫・食材・調味料・選択状態をJSONでバックアップ／復元
- AI向け食材リストをクリップボードへコピー
- 接続したクラウド版では端末保存後、約3秒まとめて自動バックアップ。食材・在庫・分類・冷凍・選択・冷蔵庫・調味料の変更、削除、読み込みを対象とする
- 最新データの利用期限なし・検証済み履歴は最新5件。閲覧やタブ切替だけでは新規保存しない
- 復旧キーで初回接続後、アプリ専用のHttpOnly Cookieを保持。設定から端末の名前変更・個別取消・全取消・キー変更が可能
- 通信失敗時は端末データと同じ処理IDを保持し、接続復帰・次回起動時に再試行。認証取消時は再接続が必要
- 複数端末の自動同期は行わず、履歴から確認して復元する。復元前の端末データを退避し、確認中の編集があれば置換を中止
- アクセス解析・広告なし
- オフライン利用とホーム画面追加に対応
- `noindex` 設定済み

## 今の端末からの移行

1. 旧GitHub Pages版をいつも使っているブラウザで開き、「設定・情報」→「JSONを書き出す」で全データを保存。
2. クラウド版を開き、「設定・情報」→「クラウドバックアップ」で、このアプリ専用の復旧キーと端末名を入力して接続。
3. 同じJSONを読み込み、全冷蔵庫・食材・調味料を確認。「クラウド保存済み」と保存日時を確認。
4. クラウド版のURLをホーム画面へ追加。確認が済むまで旧アプリとJSONを保持する。

URLのオリジンが異なるため、旧版のIndexedDBは自動では引き継がれない。復旧キー原文は端末のIndexedDB・localStorage・JSON・公開コードに保存しない。

## 配備・保守

Cloudflare WorkersでアプリとAPIを同一オリジンに配信し、専用D1へ保存する。`cloudflare/migrations/`は新規DBへ順番に一度適用する。`BACKUP_TOKEN_SHA256`をSecretsへ設定し、DBを`DB`としてバインドする。更新時には既存DB・キー・セッションを作り直さず、秘密バインドを継承する。

在庫は文字データのみで、1バックアップは2MiBまで。D1の1行制限を避けて分割し、全内容を再取得してSHA-256・形式・件数を確認した後にだけ旧履歴を整理する。自動保存はアプリを開いている間に行い、ブラウザが終了している間の送信は保証しない。
