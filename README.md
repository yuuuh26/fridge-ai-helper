# 冷蔵庫AIヘルパー

冷蔵庫・冷凍庫にある食材を登録し、「必ず使う」「使ってもOK」に分類して、料理AI向けの文章をワンタップでコピーする個人用PWAです。

## 公開URL

https://yuuuh26.github.io/fridge-ai-helper/

## 主な仕様

- 食材カードのタップで3状態を切り替え
- 残量・単位・冷凍状態をIndexedDBへ自動保存
- 最大5個の冷蔵庫を切り替え。現在の冷蔵庫から完全コピー、選択状態を解除する項目コピー、空の新規作成に対応
- 既存の食材・調味料は更新時に「自宅」へ引き継ぎ、冷蔵庫ごとに独立保存
- 全冷蔵庫・食材・調味料・選択状態をJSONでバックアップ／復元
- AI向け食材リストをクリップボードへコピー
- 外部送信・アクセス解析・広告なし
- オフライン利用とホーム画面追加に対応
- `noindex` 設定済み
